# คู่มือการติดตั้งและใช้งานระบบปฏิทินกิจกรรมการศึกษา (พ.ศ. / ฮ.ศ.)

ระบบปฏิทินนี้ออกแบบมาตามสถาปัตยกรรมทางเลือกที่ 3: **Google Sheets + Google Apps Script Web App** ซึ่งทำงานได้ 2 รูปแบบ:
1. **ทดลองใช้งานทันที (Standalone Offline / Browser)**: ดับเบิลคลิกเปิดไฟล์ `Index.html` ได้ทันที (ข้อมูลจำลองจะถูกบันทึกลงในเครื่องผ่าน LocalStorage)
2. **ใช้งานออนไลน์จริงผ่าน Google Workspace / Gmail**: นำโค้ดขึ้น Google Sheets เพื่อให้ทุกคนในโรงเรียนเข้าใช้งานผ่านลิงก์เว็บแอปได้ตลอดเวลา

---

## ฟังก์ชันเด่นที่ระบบรองรับ

1. **แสดงผล 2 ศักราชคู่ขนาน (Dual Calendar)**:
   - วันที่ตามสุริยคติไทย: **พุทธศักราช (พ.ศ.)** และ **คริสต์ศักราช (ค.ศ.)**
   - วันที่ตามจันทรคติอิสลาม: **ฮิจเราะห์ศักราช (ฮ.ศ.)** พร้อมชื่อเดือนอาหรับ (เช่น มุฮัรรอม, รอมฎอน, เชาวาล, ซุลฮิจญะฮ์)
2. **วันหยุดสำคัญที่บรรจุมาให้ล่วงหน้า (Pre-loaded Holidays)**:
   - **วันสำคัญทางศาสนาอิสลาม**: วันตรุษอีดิ้ลฟิฏริ, วันตรุษอีดิ้ลอัฎฮา, วันเริ่มถือศีลอดรอมฎอน, วันปีใหม่ฮิจเราะห์ศักราช, วันอาชูรออ์, วันเมาลิดนบี
   - **วันหยุดราชการไทย**: วันขึ้นปีใหม่, วันสงกรานต์, วันฉัตรมงคล, วันเฉลิมพระชนมพรรษา, วันแม่, วันพ่อ ฯลฯ
3. **จัดการฝ่ายและสีได้อย่างอิสระ (Custom Departments & Colors)**:
   - เพิ่มฝ่ายใหม่ได้ไม่จำกัด เช่น ฝ่ายวิชาการ, ฝ่ายกิจการนักเรียน, ฝ่ายงบประมาณ, ฝ่ายแนะแนว ฯลฯ
   - มี Color Picker ให้เลือกเปลี่ยนสีประจำฝ่ายได้ตามใจชอบ
4. **การลงงานและมุมมอง**:
   - รองรับการแบ่งตาม **ปีการศึกษา** (เช่น 2567, 2568, 2569) และ **ภาคเรียน** (เทอม 1 / เทอม 2 / ปิดเทอม)
   - สลับดูได้ทั้ง **ปฏิทินรายเดือน (Month View)** และ **รายการกิจกรรม (Agenda View)**
   - กรองดูเฉพาะฝ่ายที่สนใจได้ทันที
5. **ระบบความปลอดภัยและบทบาทแอดมิน (Admin Mode)**:
   - โหมดทั่วไป: ทุกคนสามารถคลิกดูรายละเอียดกิจกรรมได้
   - โหมดแอดมิน: ยืนยันรหัส PIN (**ค่าเริ่มต้น: 1234**) เพื่อสิทธิ์ในการจัดการฝ่าย และลบกิจกรรมใดๆ

## ขั้นตอนการติดตั้งขึ้น Google Sheets (ใช้งานออนไลน์จริง)

1. เข้าไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตเปล่าใหม่
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ที่หน้าต่างโค้ด:
   - ในไฟล์ `Code.gs`: ลบโค้ดเดิมออกทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `Code.js` ในโฟลเดอร์นี้ไปวางแทน
   - กดปุ่มเครื่องหมาย `+` ด้านซ้ายเลือกสร้าง **HTML** แล้วตั้งชื่อว่า `Index`
   - คัดลอกโค้ดจากไฟล์ `Index.html` ในโฟลเดอร์นี้ไปวางแทน
4. กดปุ่มบันทึก (รูปแผ่นดิสก์ หรือ Ctrl + S)
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน -> เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท (Type): เลือก **เว็บแอป (Web app)**
   - คำอธิบาย (Description): `ระบบปฏิทินกิจกรรมการศึกษา v1.0`
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** (เพื่อให้ผู้ใช้ทั่วไปและครูเปิดดูผ่านมือถือ/คอมพิวเตอร์ได้)
6. กด **ทำให้ใช้งานได้ (Deploy)** และให้สิทธิ์การเข้าถึง (Authorize access)
7. จะได้รับ **URL ของเว็บแอป (Web app URL)** สามารถส่งลิงก์นี้ให้ทุกฝ่ายและผู้ใช้ทั่วไปเข้าใช้งานได้ทันที
